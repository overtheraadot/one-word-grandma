Entry for make.fun's "One Word From Grandma" bounty: exactly one word — the word
grandma would text about AI. This entry picks a typo-style word, the kind of
doubled-letter slip a grandma actually makes while typing about a robot on her
phone. `main.py` writes that single word to `entry.txt`, deterministically, with
no network and no model calls.
